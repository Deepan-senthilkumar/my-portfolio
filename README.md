A responsive, modern personal portfolio website built with clean HTML5, CSS3, and JavaScript.

## 🛠️ Built With

- **HTML5**: Semantic tags, accessibility attributes, and SEO-friendly structure.
- **CSS3**: Custom design system, responsive flexbox & grid layouts, micro-animations, glassmorphism, and dark theme palette.
- **JavaScript (ES6+)**: Mobile navigation drawer, scroll reveal via IntersectionObserver, and animated stats counter.
- **Google Fonts**: Inter & Plus Jakarta Sans typography.

## 💻 Running Locally

You can run this project locally without any complex build tools:

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Deepan-senthilkumar/my-portfolio.git
   cd my-portfolio
   ```

2. Open with VS Code Live Server or run a local HTTP server:
   ```bash
   # Using Python
   python -m http.server 3000

   # Or using npx serve
   npx serve .
   ```

3. Open your browser and navigate to `http://localhost:3000`.
